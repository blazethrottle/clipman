clipman 0.2.0 개인 시험용 Chrome 확장

스토어 등록 없이 본인 Chrome에서 사용할 수 있습니다.

1. ZIP을 압축해제하고 이 폴더를 계속 보관합니다.
2. Chrome 퍼즐 메뉴의 확장 프로그램 관리에서 개발자 모드를 켭니다.
3. '압축해제된 확장 프로그램을 로드합니다'를 누르고 manifest.json이 있는 이 폴더를 선택합니다.
4. clipman 아이콘을 도구 모음에 고정하고 YouTube 탭을 새로고침합니다.
5. 이 PC의 clipman 작업 폴더에서 start.cmd를 엽니다.
6. 연결 안내 페이지의 연결 코드를 확장 패널에 붙여 넣습니다.
7. 시작/끝 표시 -> 이 구간 편집하기 -> 쇼츠 만들기 -> MP4 저장 순서로 사용합니다.

이 ZIP에는 확장 화면만 포함되어 있습니다. 로컬 영상 처리 프로그램과 실행파일은 별도입니다.
다른 PC에서 ZIP만 로드하면 영상 처리가 설치되는 것은 아닙니다.
업데이트 뒤 확장 관리의 새로고침 버튼을 누르고 YouTube 탭도 새로고침합니다.
같은 포트에서 서버를 다시 실행하면 기존 연결을 유지합니다. 포트나 키가 바뀐 경우에만 다시 연결합니다.

개발용 개인 설치 패키지입니다. 스토어 심사/게시 및 일반 사용자용 설치 프로그램은 아직 완료하지 않았습니다.
